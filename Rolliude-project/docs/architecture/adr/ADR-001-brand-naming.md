# ADR-001 Brand Naming

Status: Accepted

Context

The project materials contain variations of the brand name.

Decision

The official display name is Rolliúde Play. The technical slug is `rolliude-play`.

Alternatives considered

Roliúde Play and Rolliude Play.

Consequences

User-facing text must use Rolliúde Play. Technical package names and slugs use `rolliude-play`.

2026-09-21
